L'accord du participe passé

Un exercice de Sid KHALIFA
À retenir : avec être, le participe passé s'accorde avec le sujet. Avec avoir, il s'accorde avec le COD seulement si celui-ci est placé avant le verbe. Pour les verbes pronominaux, on cherche le COD : s'il est placé avant (souvent se), on accorde ; s'il est après, on n'accorde pas.
